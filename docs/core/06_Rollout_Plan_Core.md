# Rollout Plan (Core)
Product: iGO Core Smart Dock / Desktop Buddy
Version: 1.0
Date: 2026-02-06

## 1. Phase 1 - Pilot (0-3 months)
- Build 50 units
- Recruit 30-50 beta users
- Collect daily usage and reliability metrics
- Weekly firmware updates

Exit criteria:
- >= 60% daily active usage
- Alarm reliability >= 99.5%
- <= 5% hardware failure rate

## 2. Phase 2 - Early Launch (4-6 months)
- Build 500 units
- Open online sales channel
- Launch desktop and mobile apps (beta)
- Gather support tickets and improve onboarding

Exit criteria:
- 500 units sold
- Support response time <= 24 hours
- App rating >= 4.0

## 3. Phase 3 - Scale (7-12 months)
- Expand manufacturing
- Add retail partners
- Launch add-on modules (separate branches)
- Start B2B pilots

Exit criteria:
- 5,000 units sold
- 30% add-on attach rate
- >= 50 NPS

## 4. Operational Readiness
- Manufacturing QA checklist
- Firmware update pipeline
- Customer support process

## 5. Risks and Mitigations
- Supply chain delays -> dual supplier strategy
- Firmware instability -> staged rollouts
- High support load -> self-service docs and in-app help
