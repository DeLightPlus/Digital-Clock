# Core Overview (1-Page)
Project: iGO Core Smart Dock / Desktop Buddy
Date: 2026-02-06

## What It Is
A compact, always-on desktop companion that provides time, alarms, reminders, tasks, and notifications. It stays reliable during power outages and syncs when connected.

## Who It Serves
- Students and professionals who need reliable scheduling
- Households impacted by power cuts
- Small businesses needing simple, visible reminders

## Core Value
- Always-on display for critical information
- Works offline and during power loss
- Affordable, no mandatory subscriptions
- Clear upgrade path without hardware waste

## Core Features (MVP)
- Time, alarms, timer, stopwatch
- Basic tasks and notes
- Notifications and reminders
- Load-shedding awareness and battery status
- Multi-device access (USB desktop app, WiFi web app, BLE mobile)

## Key Constraints
- Low BOM cost
- Embedded resources are limited
- Offline-first behavior is non-negotiable

## Success Metrics
- Daily active usage >= 60% (pilot)
- Alarm reliability >= 99.5% during power outage
- NPS >= 50
